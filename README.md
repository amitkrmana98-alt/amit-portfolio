# Amit Manna - Portfolio

Personal Portfolio application for Amit Manna (Finance • Operations • Strategy).

## Repository & Deployment Instructions

To configure the remote origin and push to GitHub, run the following commands in your terminal:

```bash
git remote add origin https://github.com/amitkrmana98-alt/amit-portfolio.git
git branch -M main
git push -u origin main
```

Alternatively, you can run:
```bash
npm run push-github
```
or
```bash
./push-github.sh
```
